# Wie adlerianisch denkst du?

Selbsttest nach Alfred Adler – Geschichte-Referat der 8a (Niki, Rupert, Oscar, Ano).

- Test: https://nikiweikhart.github.io/adler-test/
- Klassenauswertung (Beamer): https://nikiweikhart.github.io/adler-test/klasse.html

Teil A (8 Aussagen) ergibt Adlers Lebensstil-Typ, Teil B (6 Situationen) den Adler-Wert (0–18).
Ergebnisse werden anonym in Supabase gespeichert (nur Einfügen/Lesen erlaubt, siehe `supabase.sql`).
